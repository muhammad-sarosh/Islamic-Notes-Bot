# Aqeedah Notes Rules

## Source Rules

- Use the lecture transcript as the primary source.
- Use the provided Aqeedah course PDF/material only as a supporting reference, especially when the transcript is unclear.
- Keep theological claims tied to what was stated in the lecture.
- Do not add theological conclusions or interpretations that were not actually stated.
- If the transcript is unclear, use the supporting PDF/material only to clarify the point, not to introduce unrelated material.
- If a point is only from the PDF/material and not clearly from the lecture, either omit it or clearly mark it as supporting material.

## Aqeedah Accuracy Rules

- Preserve important:
  - definitions
  - distinctions
  - categories
  - theological claims
  - evidences
  - objections or doubts
  - responses to objections
  - differences between correct and incorrect beliefs when explicitly discussed
- Do not weaken or blur distinctions the Shaikh makes between beliefs or categories.
- If the lecture distinguishes between concepts such as Tawheed, shirk, kufr, iman, or similar terms, preserve those distinctions carefully.
- If a Qur'an verse or Hadith is used as evidence for a theological point, keep the evidence connected to that point.
