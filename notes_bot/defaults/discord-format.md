# Discord Formatting Rules

- Format the notes as clean Discord-ready Markdown.
- Use bold headings.
- Use bullet points for normal points.
- Use numbered lists only when the lecturer explicitly gives a numbered list or sequence.
- Keep related information grouped together instead of splitting every sentence into its own bullet.
- Leave a blank line between major sections.
- Do not use Markdown tables.
- Do not use HTML.
- Do not use footnotes.
- Do not use task-list checkboxes.
- Do not add code blocks unless the lecture content specifically requires code.
- Do not add an empty line after the heading.
- Keep formatting simple and readable when pasted directly into Discord.

## Lecture Heading Format

Use this format:

**Lecture X / Y**
General Topic Title

- `X / Y` must come from the supplied `lecture_number`.
- Add one short general topic title directly below the lecture number.
- Keep the topic title concise and based on the actual lecture content.

Example:

**Lecture 1 / 7**
Introduction to Mustalah al-Hadith
